# Dinner Dial

Spin a lazy-Susan wheel to pick where to eat, anywhere from Fort Lauderdale down to Key Largo along the east side of South Florida.

Stack filters for neighborhood, distance (from a starting area or your current location), type of food, cost, stars, fancy/elegant, fast/quick bite, sweet treats (dessert shops and restaurants known for a great dessert), waterfront, outdoor seating, date night, family-friendly, brunch, late night, veggie-friendly, Michelin-recognized and local legends.

## Run it

Open the GitHub Pages link. No keys or setup needed. On a phone, use Share → Add to Home Screen to run it full screen.

Star ratings and prices are approximate. Hours and seasons change, so check before you go.
